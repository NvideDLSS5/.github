## 🧠 Overview

DLSS 5 Swapper is a Windows-focused utility for managing supported NVIDIA graphics components and related game configurations. It aims to make graphics-file handling more straightforward by bringing compatible titles and available modification options into a single workflow. Users can review detected game installations, apply supported changes, and preserve original files when backup options are provided. The features available in practice depend on the tool version, the target game, installed drivers, and compatible graphics hardware.

| Feature | Description |

| 🧠 DLSS Component Management | Work with compatible DLSS-related files where the selected game and tool version allow it. |

| 🛠️ Diagnostic Support | Use available status details to help investigate errors or unsuccessful changes. |
| 🎯 Configuration Testing | Compare supported setups to find a suitable balance between visual quality and system performance. |

## Additional Information for Windows Users

Before changing any game files, close the game and create a backup of its original configuration. Graphics features are dependent on hardware and software support, so not every option will work with every title. Game updates, other modifications, and anti-cheat software may also affect compatibility. Apply changes carefully, test each game after modification, and restore the original files if you encounter crashes, rendering errors, or unexpected performance changes.
